# Legacy market CSV inputs

`AllIndices_01012026.csv` and `AllIndices_02012026.csv` are the two bundled market
index inputs for the administrator-only PostgreSQL example in
[sql_queries.sql](../sql_queries.sql). They are separate from the synthetic retail
fixture generated by `assistant.demo`; the current retail evaluation never loads
these CSVs.

The SQL example links to the BSE index archive, but the exact download provenance,
licensing, and original author of these files are not recorded. Do not infer that
redistribution or production use is approved. Preserve the CSV
headers, values, and filenames so the example import contract remains intact.
The SQL script contains an administrator/loader example and must be reviewed for
local paths before use; assistant credentials must remain read-only.
