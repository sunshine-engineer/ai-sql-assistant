# UI media

The root PNG files are retained legacy interface screenshots referenced by the
README. Their exact capture revision and original author are not recorded; do not
present them as screenshots of every current feature. They contain demonstration
UI states rather than executable fixtures.

[current/](current/README.md) contains the dated reviewer walkthrough, screenshots,
and video provenance. New captures should use a separate output directory until
reviewed. Media bytes are preserved during documentation/formatting changes;
metadata belongs in these READMEs, not injected into the image/video files.
